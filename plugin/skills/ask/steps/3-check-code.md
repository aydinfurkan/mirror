# Check the code

Skip this step when the mirror answers the question and the user does not ask about the
code.

1. Find the code of a flow or page from the mirror:
   - the `root` of its project in `.mirror/xsrc/config.json`;
   - the `entry` in its `definition.md`: the endpoint, the route, the topic or the script.
2. Search for the `entry` under the `root`. Open that file first. Then follow the names of
   the steps in `steps.md` or the actions in `actions.md`.
3. Read only the code of the flows and pages in your list. Do not scan the whole repository.
4. When the code does not do what the mirror says, keep the difference for the answer. Do not
   change the mirror or the code.
